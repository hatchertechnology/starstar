**Mechanics that bit us:**
- The Codex sandbox protects `.git`, so the controller commits each task with `Co-Authored-By: Codex gpt-6.1-terra <noreply@openai.com>`.
- `scripts/task-brief` and `scripts/review-package` print `wrote <path>: …`, so take the path with `sed -n 's/^wrote \(\S*\).*/\1/p'`.
- Rust tests need Postgres. Start a disposable container, write its URL to `<workspace>/db-url` (never print it), and give agents `export STARSTAR_TEST_DATABASE_URL=$(cat …/db-url)`. The previous container has been removed.
- The classifier refuses: approving a child agent's permission prompts; `danger-full-access` for child agents; reading `~/secrets` directly.
- `kubectl` always needs `--context thor`, because the default context is a DigitalOcean cluster. In zsh, use a function such as `k(){ kubectl --context thor "$@"; }`, not `$VAR`, because zsh doesn't split words in variables.
